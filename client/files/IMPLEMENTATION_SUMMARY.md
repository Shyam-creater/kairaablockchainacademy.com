## 🆘 Common Issues & Solutions

### Issue: Colors look different in dark mode
**Solution**: Use CSS variables in Tailwind - they handle dark mode automatically

### Issue: Components not responsive
**Solution**: Always use mobile-first: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`

### Issue: Text too small on mobile
**Solution**: Base size 16px, scale up with: `text-base md:text-lg lg:text-xl`

### Issue: Forms not accessible
**Solution**: Use FormGroup component - it handles all accessibility

### Issue: Images slow down page
**Solution**: Optimize with WebP, use srcset, lazy load below-fold images
