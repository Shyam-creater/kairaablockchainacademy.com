What is Kairaa Academy LMS?

A blockchain-focused e-learning platform where students discover, purchase, and complete DRM-protected video courses. Admins control all content and operations; staff manage student support and live sessions; users learn at their own pace and earn certificates.

Core purpose

Sell & deliver courses

  • Blockchain / crypto education niche
  • Paid courses gated behind Razorpay
  • DRM video via VdoCipher (no download)
  • Certificates on 100% completion
  • Live sessions via scheduled links
Business model

Revenue streams

  • One-time course purchase (primary)
  • Coupon / discount codes (admin-issued)
  • Bundle deals (group of courses)
  • Live workshop tickets (optional)
  • Affiliate referral codes (future)
Platform scope

What gets built

  • Public marketing site + course catalogue
  • Student learning portal (protected)
  • Admin control panel (full CMS)
  • Staff support dashboard
  • REST API + real-time Socket.io layer
Key constraints

Non-negotiables

  • Video URLs never exposed to browser
  • Payment verified server-side only
  • JWT in httpOnly cookies (no localStorage)
  • Role middleware on every protected route
  • OTP email verification before access

The 3 roles at a glance

Super user

Admin

Full system access. Creates courses, manages users, views all revenue, controls site appearance. Cannot be created from signup — only promoted in DB.

Operations

Staff / Instructor

Creates and manages their own courses and live sessions. Views their own analytics. Can respond to Q&A in their courses. Cannot see other instructors' revenue.

Learner

User / Student

Browses free content, purchases courses, watches videos, completes quizzes, downloads certificates. Profile management and purchase history.

Course management
Create course

Title, description, price, estimated price (shows strike-through), thumbnail (Cloudinary upload), demo video URL, tags, level (Beginner/Intermediate/Advanced), prerequisites[], benefits[]. Add sections → each section has title + lessons. Each lesson: title, video upload to VdoCipher (stores videoId), description, PDF resources[].

Edit / delete course

Update any field. Reorder sections drag-and-drop. Delete removes course from DB and un-enrolls no one — already enrolled users keep access (store snapshot). Soft-delete preferred.

Video upload flow

Admin uploads video file → backend calls VdoCipher API with VIDEOCIPHER_API_SECRET → VdoCipher returns videoId → stored in lesson doc. On playback, backend generates OTP per-request. Video URL never in frontend code.

12 core system modules

Module 1

Authentication & authorization

  • Register with email + password
  • 6-digit OTP via Gmail SMTP (5 min TTL)
  • JWT access token (100 min) + refresh (3 days)
  • Tokens in httpOnly sameSite cookies
  • Silent refresh on expiry
  • Social login (Google via next-auth)
  • Role-based middleware: isAuthenticated, authorizeRoles
  • Password reset via email link
Module 2

Course management

  • Course CRUD with full schema
  • Sections & lessons with ordering
  • Thumbnail via Cloudinary
  • Demo video (public) + lesson videos (DRM)
  • Prerequisites & benefits arrays
  • Course publish/draft toggle
  • Search, filter, sort, pagination
  • Related courses recommendation
Module 3

Video delivery (VdoCipher)

  • Upload video → VdoCipher stores & encodes
  • Backend calls VdoCipher API for OTP per play
  • OTP + playbackInfo sent to frontend
  • VdoCipher iframe player renders video
  • Username watermark on all videos
  • No direct video URL ever in browser
  • Supports subtitles / captions upload
Module 4

Payment (Razorpay)

  • POST /order/create → Razorpay order_id
  • Frontend opens Razorpay checkout modal
  • On success: payment_id + signature sent to BE
  • BE verifies HMAC signature
  • Only on verify: user enrolled, Order doc saved
  • Webhook endpoint as backup verify
  • Coupon discount applied before order creation
  • Email receipt via SMTP after enrollment
Module 5

User management

  • Profile CRUD (name, bio, avatar)
  • Avatar upload to Cloudinary
  • Change password (verify current first)
  • Admin: get all users, change role, delete
  • User courses[] array references
  • Account deactivation (soft delete)
Module 6

Progress & completion

  • LessonProgress doc per user per course
  • Mark lesson watched (POST)
  • Calculate % completion per course
  • Section completion badges
  • Quiz attempt storage & scoring
  • Certificate trigger at 100%
  • Resume from last watched lesson
Module 7

Quiz & assessment

  • MCQ questions per section
  • Configurable pass mark (default 70%)
  • Time limit per quiz (optional)
  • Submit → score stored in DB
  • Show correct answers after submit
  • Retry allowed (configurable attempts)
  • Quiz required for cert: yes/no toggle
Module 8

Certificate generation

  • Triggered when progress = 100%
  • PDF generated server-side (pdfkit / puppeteer)
  • Contains: name, course, date, unique UUID
  • Uploaded to Cloudinary, URL stored
  • Downloadable from My Courses dashboard
  • Shareable public URL for LinkedIn
  • Verification page: enter cert ID to verify
Module 9

Notifications (real-time)

  • Socket.io server on backend
  • Admin room: new purchase, new user, new review
  • Student: course published, live session scheduled
  • Staff: new Q&A in own course
  • Notification doc: title, message, status, userId
  • Bell icon with unread count in navbar
  • Mark all read, delete, clear all
Module 10

Q&A & reviews

  • Question per lesson (authenticated users)
  • Threaded replies (admin/staff)
  • Upvote questions
  • Mark question as answered
  • Review: 1–5 stars + text per purchased course
  • Average rating updated on course doc
  • Admin can delete inappropriate reviews
Module 11

Analytics & reporting

  • Last 12 months: users, orders, revenue
  • Top courses by enrollment
  • Avg order value, conversion rate
  • Recharts: AreaChart, BarChart, LineChart
  • Date range filter
  • Staff sees own course analytics only
  • CSV export for orders
Module 12

CMS / Layout editor

  • Hero section: title, subtitle, CTA, image
  • FAQ manager: CRUD + reorder
  • Course categories manager
  • Homepage sections toggle (show/hide)
  • Email template editor (HTML preview)
  • Announcement banner (site-wide)
  • Stored in Layout collection in MongoDB

Recommended build order

Build in this sequence so every phase is testable and you never block yourself. Each phase depends only on the previous.

Phase 1 — Foundation (Week 1)

Project scaffold: Next.js 14 + Express + TypeScript. MongoDB Atlas connection. Env config. Cloudinary setup. Basic CORS + helmet. Folder structure: /controllers /routes /models /middleware /utils /services.

Phase 2 — Auth system (Week 1–2)

User model. Register → OTP → activate → JWT flow. Login / logout / refresh. isAuthenticated middleware. authorizeRoles middleware. Gmail SMTP OTP email template. Frontend: register/login/OTP pages with React Hook Form + Zod. Redux auth slice.

Phase 3 — Course CRUD (Week 2–3)

Course model + Section/Lesson embedded. Admin course builder UI: multi-step form (details → sections → pricing). Cloudinary thumbnail upload. Course catalogue page (public). Course detail page (public). Filter/search/sort.

Phase 4 — Video delivery (Week 3)

VdoCipher upload API integration. Store videoId in lesson. OTP endpoint (/video-otp/:videoId). VdoCipher player component on frontend. Enrollment guard middleware (user must own course to get OTP). Test DRM protection.

Phase 5 — Payments (Week 3–4)

Razorpay order creation. Checkout modal on frontend (razorpay npm SDK). Verify endpoint with HMAC. Enrollment logic (push courseId to user.courses). Order model. Coupon model + apply logic. Receipt email via SMTP.

Phase 6 — Learning features (Week 4)

Progress model. Mark lesson complete endpoint. % calculation. Lesson sidebar with checkmarks. Q&A: add question, add answer. Reviews: add/edit. Quiz: questions, submit, score, store result.

Phase 7 — Certificate (Week 5)

Puppeteer PDF generation (HTML template → PDF). Trigger on 100% progress. Upload to Cloudinary. Store URL in user.certificates[]. Download button in My Courses. Public verify page (/certificate/:id).

Phase 8 — Admin panel (Week 5–6)

Admin layout (dark sidebar). All users table + role management. All orders table. Analytics charts (Recharts). CMS editor (hero / FAQ / categories). Coupon CRUD. Notification center.

Phase 9 — Real-time (Week 6)

Socket.io setup on backend (attach to HTTP server). Admin room: emit on purchase, new user, new review. User room: emit on course published, session scheduled. Staff room: emit on new Q&A. Bell icon with unread count on frontend.

Phase 10 — Polish & deploy (Week 7)

Staff role scoping. SEO meta tags (Next.js metadata API). Performance: React Query caching, Cloudinary image optimization. Error boundaries. Loading skeletons. Mobile responsive QA. Deploy: Vercel (FE) + Railway/Render (BE). Upstash Redis for rate limiting.
